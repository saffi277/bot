## 1. المبادئ غير القابلة للتفاوض

هذه قرارات مثبَّتة من المالك. لا تخالفها ولا تعِد اقتراح بدائل عنها.

1. **الموقع هو المنتج. البوت قناة جلب زبائن.**
   البوت لا يستقبل صوراً ولا يعالجها. وظيفته: دليل استخدام + زر يفتح الموقع.

2. **الترميم يتم بنماذج ذكاء اصطناعي.**
   فلاتر Canvas لا تستطيع بلوغ نتيجة Remini — راجع `DISCUSSION.md §2`.
   شعار «بدون ذكاء اصطناعي» أُلغي ويجب ألا يبقى منه أثر في الكود أو النصوص.

3. **لا يوجد نظام دفع في هذه المرحلة.** ولا نجوم تلگرام.

4. **سقف الدقة إلزامي قبل أي نداء للمزوّد.**
   إرسال صورة بدقتها الأصلية للمزوّد يضاعف الفاتورة **15 مرة**. المُخرَج
   المعتمد: **سقف 2048px على الضلع الطويل**.

5. **كل نداء للنماذج يمر عبر `lib/enhance/provider.ts`.**
   ممنوع استدعاء مزوّد مباشرةً من أي مسار API أو مكوّن واجهة. سبب ذلك أن
   الانتقال لسيرفر GPU خاص عند 45 ألف صورة/شهر يجب أن يكون بتبديل ملف واحد.

6. **كل مسار يعالج صوراً يمر عبر `lib/ratelimit.ts` قبل استدعاء المزوّد.**
   هذا صمّام الأمان الوحيد ضد استنزاف الفاتورة.

## 3. الواجهة المجرّدة للمزوّد

هذا هو العقد الأهم في المشروع. أي مزوّد جديد يطبّق هذه الواجهة، ولا يتغيّر شيء
آخر في المشروع.

```ts
// lib/enhance/provider.ts

export type EnhanceRequest = {
  /** الصورة المدخلة، مصغَّرة مسبقاً على العميل */
  image: ArrayBuffer;
  /** سقف الضلع الطويل للمُخرَج. الافتراضي 2048 */
  maxOutputEdge: number;
  /** قوة الترميم 0..1 — موازنة بين الواقعية والحفاظ على الهوية */
  fidelity: number;
};

export type EnhanceResult = {
  image: ArrayBuffer;
  contentType: string;
  /** ميجابكسل المُخرَج — يُسجَّل لتتبّع التكلفة الفعلية */
  outputMegapixels: number;
};

export interface EnhanceProvider {
  readonly name: string;
  enhance(request: EnhanceRequest): Promise<EnhanceResult>;
}
```

**قواعد:**
- المزوّد لا يعرف شيئاً عن تلگرام ولا عن المستخدمين ولا عن الحدود اليومية.
- `outputMegapixels` **إلزامي** في النتيجة — بدونه لا يمكن تتبّع التكلفة الفعلية
  ومقارنتها بالمقدَّر.
- أي فشل من المزوّد يُرمى كاستثناء؛ التعامل معه مسؤولية مسار الـ API.

## 4. تدفّق الموقع

```
المستخدم يرفع صورة
   ↓
تصغير في المتصفح لسقف الدقة      ← إلزامي. رافعة التكلفة الأهم
   ↓
POST /api/enhance
   ↓
lib/ratelimit.ts — فحص الحد اليومي (Telegram ID أو IP)
   ↓
lib/enhance/provider.ts
   ↓
النتيجة → معاينة قبل/بعد → تنزيل
```

## 5. تدفّق البوت

```
/start
   ↓
رسالة ترحيب
   ↓
دليل استخدام من 3 خطوات (أزرار «التالي»)
   ↓
زر «افتح الموقع» + وسم ?ref= لقياس المصدر
```

البوت **لا** يستقبل رسائل من نوع photo ولا يعالجها.

## 6. تقسيم الملكية بين الوكيلين

الغرض من التقسيم منع تعارض الگت. لا يعدّل وكيل ملفاً يملكه الآخر بدون تنسيق
عبر Issue أو PR.

| النطاق | المسارات |
|---|---|
| **الباك-إند والبوت** | `app/api/**`, `lib/**`, `telegram-bot/**` |
| **الواجهة والتصميم** | `app/page.tsx`, `app/layout.tsx`, `app/globals.css`, `public/**` |
| **مشترك — يُنسَّق قبل التعديل** | `docs/**`, `README.md`, `package.json`, `.openai/hosting.json` |

## 7. متغيّرات البيئة

| المتغيّر | الغرض |
|---|---|
| `APP_URL` | عنوان الموقع الذي يفتحه زر البوت |
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | سرّ التحقق من أن الطلب جاء من تلگرام فعلاً |
| `ENHANCE_PROVIDER_KEY` | مفتاح مزوّد النماذج |

القيم الحقيقية **لا تدخل الگت أبداً**. `.env.example` يوثّق الأسماء فقط.

## 8. قواعد المساهمة

- **تحقّق قبل الدفع:** `npm run lint && npm run build` يجب أن يمرّا نظيفين.
- **لا تُسكِت خطأً لتمرّ البناء.** أصلح السبب.
- **لا تضف اعتماديات** إلا لحاجة حقيقية؛ المشروع خفيف عمداً.
- **النصوص للمستخدم بالعربية**، وتعليقات الكود بالإنجليزية.
- **عند تعديل قرار في `DISCUSSION.md`** حدّث الملف مع تاريخ التعديل، حتى يبقى
  الوكيل الآخر على علم.
