| `preparing` · `processing` | الحجاب والنبضة فوق صورة حقيقية، لا فوق فراغ |
| **`done`** | المقبض، وسما «قبل» و«بعد» في اتجاه RTL، والقصّ عند الحافتين |
| الخطأ | رسالة طويلة داخل الصندوق |
| الرأس مسجَّلاً | ودجت تلگرام بجانب الرصيد حين يُضبط `TELEGRAM_BOT_USERNAME` |

**تنبيه على `done` تحديداً:** وسما «قبل/بعد» انعكسا مرة سابقة ولم يُكتشف الأمر
إلا بصورة — القصّ `inset(0 0 0 X%)` يجعل «بعد» تشغل اليمين، وهو ما يخالف
الحدس في واجهة عربية.
