- «يفرّق بين خدش الورق وندبة الوجه» **فرضية اختبار لا وعد تسويقي**.

**ما كشفه التحقق (يغيّر السؤال):**

أي أن محرّك المنافس **معروف ومتاح لنا بالسعر المعلَن**. ما سُجِّل في الجولة

**وأضيف للتوثيق:** مخرجات النموذج تحمل علامة **SynthID** غير مرئية تُعرّفها

```ts
  name?: string;       // الاسم الأول للعرض، إن وُجد
}
```

الواجهة لا تعرف شيئاً عن التوقيع ولا الكوكي — تقرأ `signedIn` فقط. ابنِ الباك
متى شئت؛ الواجهة تتعامل مع `signedIn: false` بشكل صحيح حتى قبل وصوله.
